# 听见 · 总结

粘贴 B 站视频链接，自动提取音频、转写语音，并生成完整内容总结、关键洞察和主题解读。

## 最快使用方式（Windows）

1. 安装 Python 3.10 或更高版本。
2. 双击 `start-local.bat`。
3. 首次启动会自动安装依赖、Whisper 转写模型和 Qwen3.5 9B 总结模型；准备完成后会自动打开在线页面。
4. 粘贴 B 站链接并点击「一键总结」。

默认使用 `faster-whisper large-v3` 完成本地转写，随后由 `Qwen3.5 9B` 完成通用内容总结。总结模型会先识别视频主题和信息密度，再过滤明确无关的直播寒暄、点名、设备调试、刷屏互动、广告和口头禅，同时保留事实、解释、方法、案例、数字、观点依据、推理过程、风险和结论。过滤依据是信息价值而不是视频形式：对持续输出信息的课程、访谈、演讲或长视频，会覆盖全部主要分析，不会把正文当成闲聊删除。初稿生成后还会单独生成事实与逻辑查错清单，再按清单重写最终结果，检查计数、数字、因果、内容覆盖、专名解释和时间定位，并删除原文没有的扩写。输出结构和详略会根据内容自动调整，不限定特定领域。

两个模型都会优先使用 NVIDIA GPU；为避免显存冲突，转写与总结按顺序运行。默认 9B 模型约 6.6GB，在测试设备上总结约需 1 分钟；没有兼容显卡时会自动回退 CPU。首次使用需要一次性下载约 3GB 的 Whisper 模型、约 6.6GB 的 Qwen3.5 模型；首次启用 GPU 还会自动准备约 810MB 的 CUDA 12 / cuDNN 运行库，之后均可复用。整个本地流程不产生模型 API 费用。

如果更重视模型规模而不介意等待，可在启动前设置环境变量 `BILI_SUMMARY_MODEL=qwen3.5:27b`。27B 模型约 17GB，在 12GB 显存设备上会把一部分权重放入系统内存；实测同一段内容约需 10 分钟。日常一键使用建议保留默认 9B，因为最新流程已包含独立事实审校和二次重写，速度与完整性更均衡。

## GPT 增强模式

复制 `.env.example` 为 `.env.local`，填写 `OPENAI_API_KEY`，然后在页面打开「GPT 增强总结」。默认模型为 `gpt-5-mini`，可通过 `OPENAI_SUMMARY_MODEL` 调整。GPT API 会按账户用量计费，因此不属于零费用模式。

## 工作流程

```text
B 站链接
  → 读取公开视频信息 / 优先复用现有字幕
  → 无字幕时由 yt-dlp 提取音频
  → faster-whisper 本地转写
  → Qwen3.5 本地模型过滤低信息口语并提炼有效内容
  → 生成完整总结、关键洞察、主题解读与原始转写
  → 网页展示、复制、下载 Markdown、生成直达链接
```

## 目录

- `app/`：网页与 B 站信息、总结接口
- `engine/`：本地音频下载、Whisper 转写与 Qwen3.5 总结引擎
- `start-local.bat`：Windows 一键启动入口
- `.env.example`：可选模型配置

请只处理你有权访问和转写的视频，并遵守 B 站服务条款及内容版权要求。
